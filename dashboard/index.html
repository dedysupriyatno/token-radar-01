How the implied value is worked out

implied value = TVL × category multiple × growth factor × age factor, capped at $100,000,000,000 and rounded to whole dollars. The category multiple runs 0.55 for a CEX to 1.30 for Lending (1.00 when the category is unknown); the growth factor is 1 + clamp(7-day TVL change, −50%, +100%) / 200; the age factor is 1 + 0.08 × min(years since listed, 5). A protocol counts as pre-token only when the snapshot records no token for it at all — its CoinGecko id, symbol and market cap are all null. Protocols whose token already trades are counted above and left off the board, so a launch that already happened never competes with one still to come. Farm steps are written per category and chain from the snapshot’s own fields; a token is never guaranteed, so only farm with money you can afford to leave in the protocol.
